# VELA 멤버십 & 포인트 시스템 계획

기존 등급·보험(10/7/5/3%) 화면과 디자인은 그대로 두고, 포인트 기능을 단계적으로 추가합니다. 결제가 아직 완성되지 않았으므로 주문 상태 변화(구매 확정·취소·환불)에 자동으로 반응하도록 만들어 두고, 실제 결제가 붙으면 그대로 연결됩니다.

## 1단계 — 데이터와 규칙 (서버에서 강제)
- 등급/적립률/보험 설정표, 포인트 정책(1P=$0.001, 최대 20% 사용, 12개월 만료, 긴급 OFF, 예산 한도) — 관리자만 수정, 새 주문부터 적용
- 멤버십(최근 12개월 결제 완료 금액, 취소·환불 제외), 포인트 지갑, 포인트 거래 원장(7가지 유형, 잔액 전/후, 만료일, 출처), 월별 예산, 관리자 조정 감사 기록
- 주문에 상품금액·사용 포인트·적립 예정 포인트·당시 적립률 기록
- 자동 처리: 결제 시 Pending 생성 → 구매 확정 시 지급 → 취소 시 사용분 복구·Pending 취소·지급분 회수 → 부분 환불 시 비례 재계산
- 방지: 주문당 1회 적립/1회 사용, 음수 잔액 금지, 양도·현금화 불가, 고객은 직접 수정 불가, 대량 적립 감지 표시

## 2단계 — 고객 화면
- 프로필 상단: 현재 등급, 다음 등급까지 남은 금액, "Your Benefits"(적립률·보험 할인·보험 요율)
- 프로필에 VELA Wallet 메뉴: 사용 가능 / Pending / 30일 내 만료 / 누적 적립 / 누적 사용 / 거래 내역
- 상품 상세: "이 구매로 20,000 P 적립" (현재 등급 기준)
- Checkout: 보유 포인트, 직접 입력 + 최대 사용 버튼, 포인트 할인과 실제 결제금액 분리 표시

## 3단계 — 관리자 Loyalty / Points 메뉴
- 주요 지표 10개, 등급별 고객 수·평균 구매·평균 적립/사용·포인트 비용
- 설정 화면(등급 적립률, 포인트 규칙, 수수료율·예산·한도·긴급 OFF), 수동 조정(사유 필수, 감사 기록)

## 검증
- 계산 규칙 테스트(적립, 20% 한도, 80% 현금, 부분 환불, 만료)
- 로그인 상태로 Wallet·Checkout·관리자 화면 확인
- 11개 언어 문구 연결

## 참고
- 결제 미완성이라 현재 적립·사용은 시험 주문 기준으로만 동작합니다.
- 실제 운영 전 각국 법규·회계 기준 검토가 필요하며, 이를 위해 모든 설정 변경과 거래를 기록합니다.
